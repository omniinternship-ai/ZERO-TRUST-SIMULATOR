# เปิด BlockTown บนเครื่องนี้

ดับเบิลคลิก `PLAY-BLOCKTOWN.cmd` ที่โฟลเดอร์หลัก โปรแกรมจะเปิดเซิร์ฟเวอร์เฉพาะเครื่องและหน้าเมนู หากเปิดอยู่แล้วจะใช้เซิร์ฟเวอร์เดิม ต้องมี Python บนเครื่อง

ใช้ `http://127.0.0.1:8766/BlockTown/menu.html` ต่อเนื่องเพื่อให้คะแนนและตัวละครที่บันทึกในเบราว์เซอร์เชื่อมกัน การเปลี่ยนเป็น localhost, พอร์ตอื่น, file:// หรือเว็บออนไลน์เป็นคนละพื้นที่จัดเก็บข้อมูล ไม่มีการย้ายข้อมูลอัตโนมัติ

หากหน้าเมนูยังเปิดอยู่แต่กด Play แล้วเข้าไม่ได้ ให้เปิดตัวเปิดเกมอีกครั้ง เซิร์ฟเวอร์อาจหยุดเมื่อรีสตาร์ตเครื่อง ไม่ต้องล้างข้อมูลเบราว์เซอร์

ไฟล์เกมอยู่ใน `BlockTown/` และลิงก์กลับระบบหลักอยู่ที่ `ZERO-TRUST-SIMULATOR-with-statistics/index.html` ข้อผิดพลาดของเซิร์ฟเวอร์อยู่ที่ `.local/blocktown-server-error.log` ไม่แก้ไขโฟลเดอร์เผยแพร่รุ่นเก่า และไม่อัปโหลดหรือเปลี่ยนข้อมูลผู้เล่น

## โครงสร้าง
- `menu.html`, `game.html`: เมนูและเกม
- `css/`, `js/`, `js/vendor/`: สไตล์ ระบบเกม ตัวละคร และ Three.js
- `tools/blocktown_server.py`: เซิร์ฟเวอร์ท้องถิ่น
- `PLAY-BLOCKTOWN.cmd`, `Start-BlockTown.ps1`: ตัวเปิดเกม
- `GAME-INTEGRATION.md`: เอกสารการเชื่อมต่อ

ใช้พอร์ต 8766 และชื่อ key เดิมทั้งหมด จึงอ่านคะแนนและตัวละครเดิมได้จากเบราว์เซอร์เดิม โฟลเดอร์แอปเก่าเก็บเฉพาะหน้าส่งต่อเกม เพื่อรองรับลิงก์เก่า

## จำลองหน้าจอมือถือ
เปิด `http://127.0.0.1:8766/BlockTown/simulator.html` เลือกขนาดจอและกดหมุนแนวตั้ง/แนวนอน หน้าภายในใช้ iframe จริงจึงเปลี่ยน responsive breakpoints และขนาด WebGL โดยไม่รีโหลดเกม ใช้ localStorage จาก origin เดียวกัน ไม่จำลอง Android, touch hardware, device pixel ratio หรือประสิทธิภาพเครื่องจริง

## ฟาร์มหลังเมือง
แผนที่ขยายขอบเขตเดินเป็น x -43..43 และ z -72..28 ฟาร์มอยู่หลังศาลากลาง มีทางอ้อมสองข้าง หรือใช้เมนู → ไปโซนฟาร์มด้านหลัง เข้าใกล้แปลง กด E หรือปุ่มบนจอเพื่อปลูก รอ 20 วินาทีแล้วเก็บเกี่ยว ข้อมูลฟาร์มใช้ `zerotrust_farm_v1` แยกจากภารกิจและเงินจำลอง ปุ่มเล่นใหม่รีเซ็ตเฉพาะภารกิจ ไม่ล้างฟาร์ม

## Item Shop
เดินถึงหน้าร้านแล้วกด E เพื่อเข้า ภายในกด E ใกล้เคาน์เตอร์เพื่อซื้อ หรือใช้ปุ่มบนจอ ปีก LV1/3/10 วงแหวน และตะเกียงเป็นของตกแต่ง ซื้อแล้วใส่/ถอดและบันทึกใน `zerotrust_shop_v1` เหรียญร้านเริ่ม300 บวก25ต่อการเก็บเกี่ยวหนึ่งครั้ง ระดับเริ่ม1และเพิ่ม1ทุก2ครั้ง ไม่มีการเติมเงินจริง แยกจากเงินจำลองในสถานการณ์ ร้านเป็นฉากสามมิติภายในที่แยกพิกัดจากเมืองแต่ใช้ตัวละครเดียวกัน
