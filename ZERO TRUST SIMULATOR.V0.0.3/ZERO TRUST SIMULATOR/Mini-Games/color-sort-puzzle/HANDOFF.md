## 1. ข้อมูลสรุปและกติกาการเล่น (Gameplay & Rules)

- **แนวเกม:** Color Sort Puzzle (Water / Liquid Tube Sort Puzzle) ธีมห้องทดลอง Zero Trust Isolation
- **กติกาหลัก:**
  - มีหลอดแก้วทดลอง (Tubes) ความจุหลอดละ 4 ส่วน
  - ผู้เล่นต้องแตะเลือกหลอดต้นทาง และแตะหลอดปลายทางเพื่อเทของเหลวสี
  - **เงื่อนไขการเท:**
    - หลอดปลายทางต้องยังไม่เต็ม (< 4 ส่วน)
    - หลอดปลายทางต้องเป็นหลอดว่าง **หรือ** มีสีบนสุดตรงกับสีบนสุดของหลอดต้นทาง
    - หากสีบนสุดของหลอดต้นทางมีสีเดียวกันติดกันต่อเนื่องหลายส่วน จะถูกเทไปพร้อมกันเท่าที่หลอดปลายทางมีที่ว่าง
  - **เงื่อนไขผ่านด่าน:** หลอดทดลองทุกหลอดที่มีของเหลว ต้องมีสีเดียวกันครบทั้ง 4 ส่วน (หลอดที่เหลือเป็นหลอดว่าง)
  - **การป้องกันของเหลวล้นขอบหลอด (Overflow & Rim Headspace):** กำหนดพื้นที่ว่างปากหลอด (Headspace) 14px ด้านบนของหลอดทดลอง และแบ่งความสูงแต่ละส่วนเป็น Relative Percentage (25% ต่อชั้น) จึงรับประกันว่าของเหลวจะไม่ล้นขอบหลอดแก้วเด็ดขาด แม้ในด่านที่มี 7-9 หลอด หรือบนหน้าจอขนาดเล็ก
  - **ระบบอนิเมชั่น (Visual & Fluid Animations):**
    - **อนิเมชั่นยก (Lift & Hover):** เมื่อแตะเลือกหลอด หลอดจะลอยขึ้นสูง `-28px` ถึง `-34px` พร้อมแสงนีออนเรืองรอบหลอดและการแกว่งตัวนุ่มนวล (Smooth bobbing)
    - **อนิเมชั่นเคลื่อนและเอียงเท (Fly, Tilt & Pour):** เมื่อแตะหลอดเป้าหมาย หลอดต้นทางจะเคลื่อนไปจ่อปากหลอดปลายทาง เอียงทำมุม 68° ปล่อยสายของเหลวเรืองแสง (Liquid Pour Stream) พร้อมเอฟเฟกต์ระลอกคลื่นน้ำกระเพื่อม (Splash Ripple) และเสียงเทฟองอากาศ
    - **อนิเมชั่นระดับน้ำ (Fluid Level Transition):** ของเหลวในหลอดต้นทางจะลดระดับลง และในหลอดปลายทางจะเพิ่มระดับขึ้นอย่างต่อเนื่อง
    - **อนิเมชั่นกลับที่เดิม (Smooth Return):** เมื่อเทเสร็จ หลอดต้นทางจะหมุนกลับและเคลื่อนตัวลงสู่แท่นวางเดิมอย่างเป็นธรรมชาติ พร้อมระบบล็อค Input ระหว่างเทเพื่อป้องกันอาการกระตุกหรือ Race condition
  - **ระบบการตั้งค่าเสียงและเมนูควบคุม (Settings System):**
    - **ปุ่ม Settings บนซ้าย:** ปุ่มไอคอน `⚙️` อยู่ด้านซ้ายบนของหน้าจอ แตะเพื่อเปิดหน้าต่างตั้งค่า
    - **แถบเลื่อนปรับเสียงดนตรี (Music Volume Slider):** ปรับระดับเสียงสังเคราะห์ดนตรีพื้นหลัง Ambient Cyber Synth (0% ถึง 100%)
    - **แถบเลื่อนปรับเสียงเอฟเฟกต์ (SFX Volume Slider):** ปรับระดับเสียงเอฟเฟกต์การเท หลอดแก้ว และเสียงสัมผัส (0% ถึง 100%)
    - **ปุ่มควบคุมด้านล่าง 2 ปุ่ม:**
      - **ปุ่มซ้าย ("◀ กลับสู่เกม"):** ปิดหน้าต่างการตั้งค่าและเล่นต่อทันที (Timer กลับมาเดินต่อ)
      - **ปุ่มขวา ("🔄 เริ่มใหม่"):** เริ่มเล่นด่านปัจจุบันใหม่ตั้งแต่ต้น พร้อมปิดหน้าต่างการตั้งค่า
  - **การดำเนินด่าน (13 Progressive Levels ต่อ 1 รอบ):**
    - **ด่าน 1 (Alpha 01):** 4 หลอด (2 สี: ฟ้า, ชมพู + 2 หลอดว่าง) -> 7 คะแนนดิบ
    - **ด่าน 2 (Alpha 02):** 5 หลอด (3 สี: ฟ้า, ชมพู, เขียว + 2 หลอดว่าง) -> 7 คะแนนดิบ
    - **ด่าน 3 (Alpha 03):** 5 หลอด (3 สี: ฟ้า, ชมพู, เขียว + 2 หลอดว่าง) -> 7 คะแนนดิบ

    - **ด่าน 5 (Beta 05):** 6 หลอด (4 สี: ส้ม, ชมพู, ฟ้า, เขียว + 2 หลอดว่าง) -> 7 คะแนนดิบ
    - **ด่าน 6 (Beta 06):** 6 หลอด (4 สี: ม่วง, ฟ้า, เขียว, ส้ม + 2 หลอดว่าง) -> 8 คะแนนดิบ
    - **ด่าน 7 (Gamma 07):** 7 หลอด (5 สี: ฟ้า, ชมพู, เขียว, ส้ม, ม่วง + 2 หลอดว่าง) -> 8 คะแนนดิบ
    - **ด่าน 8 (Gamma 08):** 7 หลอด (5 สี: ม่วง, ส้ม, เขียว, ฟ้า, ชมพู + 2 หลอดว่าง) -> 8 คะแนนดิบ
    - **ด่าน 9 (Delta 09):** 7 หลอด (5 สี: แดง, ฟ้า, ชมพู, เขียว, ส้ม + 2 หลอดว่าง) -> 8 คะแนนดิบ
    - **ด่าน 10 (Delta 10):** 8 หลอด (6 สี: แดง, น้ำเงิน, เขียว, ส้ม, ม่วง, ฟ้า + 2 หลอดว่าง) -> 8 คะแนนดิบ

- **การคิดคะแนนดิบ:**
  - ผ่านด่าน 1 ถึง 5: ด่านละ +7 คะแนน (รวม 35 คะแนน)
  - ผ่านด่าน 6 ถึง 12: ด่านละ +8 คะแนน (รวม 56 คะแนน)
  - ผ่านด่าน 13: +9 คะแนน (รวม 9 คะแนน)
  - รวมคะแนนสูงสุด: 100 คะแนนเต็ม
  - หากหมดเวลาหรือกดยอมแพ้ (Surrender): คิดคะแนนสะสมตามจำนวนด่านที่ผ่านได้จริง

  - คะแนนดิบ 100 (ผ่านครบทั้ง 13 ด่าน): มอบ **20 แต้ม**
  - คะแนนดิบ 60–99: มอบ **10 แต้ม**
  - คะแนนดิบ 30–59: มอบ **5 แต้ม**
  - ต่ำกว่า 30: 0 แต้ม
  - *หมายเหตุ:* สถานะเป็นข้อเสนอ (`proposal-only`) ให้ผู้ดูแลระบบ Simulation เป็นผู้กำหนดใน Game Registry ฝั่ง Host

## 4. มาตรฐานโปรโตคอล (Protocol Compliance: zt-minigame/1)

1. **Handshake:**
   - เมื่อเปิดใน iframe เกมส่งข้อความ `{ channel: 'zt-minigame', version: 1, type: 'ready', ... }` ทุก 1.5 วินาที
   - Host ส่ง `{ type: 'init', sessionId, runId, ... }` เกมจึงเริ่มนับเวลาและรับ input
   - Host ส่ง init ซ้ำด้วย session/run เดิม เกมจะไม่รีเซ็ตตัวเอง
2. **Lifecycle Control:**
   - รองรับคำสั่ง `pause`: หยุด input, หยุดตัวจับเวลา, หยุดเสียง
   - รองรับคำสั่ง `resume`: เล่นต่อโดยไม่สูญเสียเวลาที่เหลือ
   - รองรับคำสั่ง `stop`: ปิดการทำงานทั้งหมดทันที
   - ตรวจจับ `document.visibilitychange`: เมื่อแท็บถูกซ่อน จะพักเกมทันที
3. **การส่งผลและการป้องกันซ้ำ (Idempotency & Retry):**
   - ส่งผลชนิด `result` เพียงครั้งเดียวต่อรอบ
   - มี `eventId` กำกับ หาก host ยังไม่ตอบ ack เกมจะ retry ด้วย `eventId` เดิมสูงสุด 3 ครั้ง
   - หาก retry ครบแล้วยังไม่ได้รับ ack จะแสดงปุ่ม "ลองส่งผลซ้ำ" โดยคง `eventId` เดิมไว้ ไม่เพิ่มคะแนนและไม่เปลี่ยน runId
   - Replay: เมื่อผู้เล่นกดเล่นใหม่ จะส่ง `replay-request` และรอรับ `runId` ใหม่จากโฮสต์ก่อนเริ่มรอบใหม่
4. **โหมดเล่นแยก (Standalone Mode):**
   - เมื่อเปิด `index.html` ตรงๆ หรือไม่มี `hostOrigin` จะเข้าโหมดฝึกซ้อม
   - มีป้ายแจ้งชัดเจน: *"โหมดเล่นแยก (ไม่บันทึกคะแนนจริง)"*
   - ไม่มีการจำลองส่ง API หรืออ้างว่าบันทึกคะแนนออนไลน์สำเร็จ

## 5. วิธีรันและทดสอบ (Running & Verification)

### ก. ทดสอบ Standalone (เล่นแยก)
1. เปิด static web server ในโฟลเดอร์โครงการ:
   ```sh
   # ตัวอย่างคำสั่งรัน HTTP Server
   npx serve .
   # หรือเปิด index.html ผ่าน Live Server ใน IDE
   ```
2. เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:8080/color-sort-puzzle/index.html`
3. ตรวจสอบว่ามีแถบแจ้งโหมดเล่นแยก และเล่นได้ปกติจนจบ 3 ด่าน

### ข. ทดสอบกับ Mock Host
1. เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:8080/color-sort-puzzle/test-host.html`
2. ทดสอบกรณีต่างๆ:
   - **Normal Play:** เล่นจนจบ 3 ด่าน -> Host รับรองผล แสดงคะแนนจำลอง 20 แต้ม
   - **Rotate:** กดปุ่ม "สลับแนวตั้ง/แนวนอน" -> ตรวจสอบ UI ปรับตัวตามขนาดหน้าจออย่างสวยงาม
   - **Duplicate Result:** กดปุ่ม "ส่งผลซ้ำ" -> Host ตอบ receipt เดิม ไม่เพิ่มคะแนนสะสม
   - **Drop Ack / Retry:** ติ๊ก "ไม่ตอบรับผล" -> เกมจะ retry อัตโนมัติด้วย eventId เดิม
   - **Pause / Resume:** ทดสอบพักและเล่นต่อ
   - **Replay:** กดปุ่ม "เล่นอีกรอบ" ในเกม -> Host ออก runId ใหม่และเริ่มรอบใหม่
